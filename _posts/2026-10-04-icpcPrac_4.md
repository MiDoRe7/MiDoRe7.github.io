## 1. 오일러 피 함수
오일러 피 함수 $\varphi(n)$는 자연수 $n$ 이하의 양의 정수 중에서 $n$과 서로소인 수의 개수를 나타낸다.
$$\varphi(n) = {1 \leq k \leq n | gcd(k, n) = 1}$$

```cpp
ll phi(ll x)
{
    ll r = x;
    for (ll d = 2; d * d <= x; d++)
    {
        if (x % d == 0)
            r = r / d * (d - 1);
        while (x % d == 0)
            x /= d;
    }
    if (x != 1)
        r = r / x * (x - 1);
    return r;
}
```

## 2. 가우스의 오일러 피 함수 항등식
$n$의 모든 약수 $d$에 대해 $\varphi(d)$를 더한 것이 $n$과 같다는 항등식이다.

$$n = \sum_{d|n} \varphi(d)$$

## 3. GCD 격자 합
### 문제
양의 정수 N이 주어질 때 다음 값을 구하시오.

$$S(N) = \sum_{i=1}^{N}\sum_{j=1}^{N} \gcd(i, j)$$

### 입력
첫 줄: 테스트 케이스 수 $T (1 ≤ T ≤ 10⁵)$
다음 T줄: 각각 정수 $N (1 ≤ N ≤ 10⁶)$

### 출력
각 테스트 케이스마다 $S(N)$을 한 줄에 출력한다.

### 풀이
$n = gcd(i, j)$으로 놓자.
$$S(N) = \sum_{i=1}^{N}\sum_{j=1}^{N}\sum_{d \mid \gcd(i,j)} \varphi(d)$$

$d \mid \gcd(i,j) \iff d \mid i \text and d \mid j$ 이므로 조건이 i, j 각각으로 분리, d를 바깥으로 옮기면
$$S(N) = \sum_{d=1}^{N} \varphi(d) \cdot \#\{(i,j) : d \mid i,\; d \mid j\}$$

$⌊N/d⌋$가 가질 수 있는 값은 약 $2\sqrt{N}$가지뿐, 값이 $q$로 같은 $d$의 구간 $[l, r] (r = ⌊N/q⌋)$에서는 $q²$이 공통이므로

$$\sum_{d=l}^{r} \varphi(d)\, q^2 = \big(P(r) - P(l-1)\big)\, q^2, \qquad P(x) = \sum_{d=1}^{x} \varphi(d)$$

$\varphi$와 누적합 $P$를 $10⁶$까지 미리 구해 두면 각 구간을 $O(1)$에 처리 가능

### 코드
```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int M = 1000000;
ll P[M + 1];

ll phi(ll x)
{
    ll r = x;
    for (ll d = 2; d * d <= x; d++)
    {
        if (x % d == 0)
            r = r / d * (d - 1);
        while (x % d == 0)
            x /= d;
    }
    if (x != 1)
        r = r / x * (x - 1);
    return r;
}

int main()
{
    for (int i = 1; i <= M; i++)
        P[i] = P[i - 1] + phi(i);

    int T;
    scanf("%d", &T);
    while (T--)
    {
        ll n;
        scanf("%lld", &n);
        ll ans = 0;
        for (ll l = 1, r; l <= n; l = r + 1)
        {
            ll q = n / l;
            r = n / q;
            ans += (P[r] - P[l - 1]) * q * q;
        }
        printf("%lld\n", ans);
    }
}
```
