## 1. 오일러 피 함수
오일러 피 함수 $phi(n)$는 자연수 $n$ 이하의 양의 정수 중에서 $n$과 서로소인 수의 개수를 나타낸다.
$phi(n) = {1 \leq k \leq n | gcd(k, n) = 1}

```cpp
ll phi(ll x)
{
    ll r = x;
    for (ll d = 2; d * d <= x; d++)
    {
        if (x % d == 0)
            r = r / d * (d - 1);
        while (x % d == 0)
            x /= d;
    }
    if (x != 1)
        r = r / x * (x - 1);
    return r;
}
```

## 2. 가우스의 오일러 피 함수 항등식
$n$의 모든 약수 $d$에 대해 $phi(d)$를 더한 것이 $n$과 같다는 항등식이다.

$n = \sum_{d|n}phi(d)$

양의 정수 N이 주어질 때 다음 값을 구하시오.

$$S(N) = \sum_{i=1}^{N}\sum_{j=1}^{N} \gcd(i, j)$$
