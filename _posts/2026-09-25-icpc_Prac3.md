## Binary Grid
You are given an array $A$ containing $N$ non-negative integers. You have to construct a binary grid of size $N × M$ such that:
 * for any cell with value 1, any of its adjacent cells, i.e. cells that share one of its four sides, must not have the value 1.
 * the number of cells with value 1 in row i is exactly $A_i$.
Find any such binary grid or tell that it’s impossible to construct.

Input
 * The first line contains two integers $N$ and $M$ ($1 ≤ N, M ≤ 1000$). The next line contains $N$ integers containing $A_i$ ($0 ≤ A_i ≤ M$).

Output
 * Output $N$ lines, each containing $M$ characters of either $0$ or $1$ representing the binary grid you constructed.
 * If multiple construction exists, you may output any of them. If such a grid does not exist, output $−1$.

- - -
## 문제 해석
$N × M$의 Grid를 0과 1로 채우되, 1의 사방에 같은 1이 붙어서는 안되는 조건을 가지고 있다.
불가능한 경우를 판정하는 건 어렵지 않지만, 가능한 경우에는 가능한 Grid의 예를 출력해야 한다.

짝/홀 열 교대같은 단순 Greedy로 풀기에는 반례가 있어서 단순한 교대로는 만들 수 없고, 조건을 나눠 엄밀하게 판정해야 했다.

### M % 2 == 0
$M$이 짝수인 경우 모든 $A_i \leq M/2$이면 항상 가능하다.
체스판을 생각하고 $i$행에 $i mod 2$열부터 시작해서 2열씩 건너뛰며 $A_i$개를 배치하고 끝이다.

### M % 2 == 1
$M$이 홀수인 경우 다양한 조건이 생긴다.
1. $M = 2k+1$로 두고 $A_i \leq M/2 \forall A_i$이어야 한다.
2. $A_i = k+1$인 행을 full 행이라고 하자. full행은 ${1, 3, ..., 2k+1}$로 강제된다.
3. full 행 두 개가 인접한 경우 불가능하다.
4. full 행에 인접한 행은 짝수 열만 사용 가능하다.
5. 두 full 행 사이의 구간에서 해당 구간의 길이를 $L$이라고 할 때
   * $L$이 홀수이거나 한쪽 끝이 Grid의 경계이면, 짝/홀 교대로 Grid를 만들 수 있다.
   * $L$이 짝수이고 양쪽이 모두 full 행이면, $d_i = k - A_i$라고 했을 때 $\Sigma d_i \geq k + 1 L/2$가 필요충분조건이다.

## 아이디어 구성
각 행을 짝수 열에 1을 채우는 parity E, 홀수 열에 1을 채우는 parity O로 구분한 후 경계 위치인 $x$를 행마다 이동시킨다.
행이 하나 진행될 때마다 x가 증가한다.
  * 짝수 번째 행 : $x$ ← $x + 1 + d_i$
  * 홀수 번째 행 : $x$ ← $x + d_i$

각 행을 E와 O로 구분했을 때 $x$는 다음 행이 왼쪽 부분에 쓸 수 있는 칸 수의 상한 = 행의 오른쪽 블록이 시작되기 직전 지점이 된다.
즉, 왼쪽 부분의 길 $L_i = min(x, A_i)$이고, $R_i = A_i - L_i$를 반대 parity로 채우면 된다.

## 풀이
```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m, k; // k = m/2 (m이 홀수면 m = 2k+1)
vector<int> A;
vector<string> g;

void fail() { printf("-1\n"); exit(0); }
void put(int r, int c) { g[r][c - 1] = '1'; }
bool full(int i) { return A[i] == k + 1; } // 홀수열을 꽉 채운 행

int main() {
	scanf("%d %d", &n, &m);
	k = m / 2;
	A.resize(n);
	for (auto& x : A) scanf("%d", &x);
	g.assign(n, string(m, '0'));

	for (int a : A) if (a > (m + 1) / 2) fail();

	if (m & 1) {
		// full 행 2개 인접 시 불가능
		for (int i = 0; i + 1 < n; i++) {
			if (full(i) && full(i + 1)) fail();
		}
		for (int i = 0; i < n;) {
			if (full(i)) {
				for (int c = 1; c <= m; c += 2) put(i, c);
				i++;
				continue;
			}
			// [i, j) = full 행 사이의 비-full 구간
			int j = i;
			while (j < n && !full(j)) j++;
			int L = j - i;
			bool top = i > 0, bot = j < n; // 위/아래가 full 행인지 확인

			if (top && bot && L % 2 == 0) {
				// 양끝이 full이고 L이 짝수 → 단순 교대 불가, x를 잡아서 이동
				long long D = 0;
				for (int r = i; r < j; r++) D += k - A[r];
				if (D < k + 1 - L / 2) fail();

				int x = k - A[i];
				for (int s = x + 1; s <= k; s++) { // 첫 행은 짝수열을 오른쪽에 밀착
					put(i, 2 * s);
				}
				for (int t = 1; t < L; t++) {
					int r = i + t, a = A[r];
					if (t & 1) {
						// 왼쪽은 짝수열, 오른쪽은 홀수열
						int q = min(x, a);
						for (int c = 1; c <= q; c++) put(r, 2 * c);
						for (int c = 0; c < a - q; c++) put(r, 2 * k + 1 - 2 * c);
						x = k - a + q + 1;
					}
					else {
						// 왼쪽은 홀수열, 오른쪽은 짝수열
						int p = min(x, a);
						for (int c = 1; c <= p; c++) put(r, 2 * c - 1);
						for (int c = 0; c < a - p; c++) put(r, 2 * k - 2 * c);
						x = k - a + p;
					}
				}
			}
			else {
				// 그 외 구간은 parity 교대. full 행에 닿는 끝 행이 짝수열
				for (int r = i; r < j; r++) {
					bool e = top ? (r - i) % 2 == 0 : bot ? (j - 1 - r) % 2 == 0 : (r - i) % 2 == 0;
					for (int t = 0; t < A[r]; t++) put(r, e ? 2 * t + 2 : 2 * t + 1);
				}
			}
			i = j;
		}
	}
	else {
		for (int i = 0; i < n; i++) {
			for (int t = 0; t < A[i]; t++) {
				g[i][2 * t + (i & 1)] = '1';
			}
		}
	}
	for (auto& s : g) printf("%s\n", s.c_str());

	return 0;
}
```
